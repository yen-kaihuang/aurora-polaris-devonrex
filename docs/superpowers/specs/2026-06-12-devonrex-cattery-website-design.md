# Aurora Polaris Devon Rex 貓舍網站 — 設計文件

## 1. 目標與背景

把現有的 Figma 設計做成一個可自行掌控的貓舍網站，**不使用 Wix 的網站建立工具**。網域目前註冊在 Wix，僅保留註冊，將 DNS 指向自有的免費託管平台。

使用者為非技術背景，主要由 AI（Claude）協助開發與說明；使用者負責「操作後台」而非寫程式。

## 2. 需求

### 功能需求
- 重現 Figma 設計的貓舍網站：首頁、種貓（Kings & Queens）、可售幼貓、貓舍介紹、Devon Rex 品種介紹、各年胎次。
- **後台可視化編輯**：使用者不碰程式碼即可維護「會變動」的內容。
- **聯絡／詢問表單**：訪客送出後以 **email 通知**貓舍（不需在後台保存表單資料）。
- **多語系**：英文（主）＋ 簡體中文（简体中文），兩種語言同時上線，可切換。
- **SEO**：可被搜尋引擎收錄，兩種語言各有獨立網址與 meta。

### 非功能需求
- 免費託管、自動部署、自動 HTTPS。
- 上線後低維護：使用者只面對一個後台介面。
- 靜態優先 → 載入快、SEO 佳。

### 明確排除（YAGNI）
- 線上金流／電商結帳。
- 表單資料存入資料庫或後台查看（僅寄 email）。
- 會員／登入系統（訪客端）。
- 部落格、後台分析儀表板。
- 繁體中文（只做英文 + 簡體中文）。

## 3. 技術選型（方案 A）

| 角色 | 選用 | 理由 |
|------|------|------|
| 網站框架 | **Astro** | 內容型網站、產生純靜態、內建 i18n、SEO 與效能佳 |
| CMS（後台） | **Sanity** | 雲端、編輯介面好用、免費額度足、照片上傳/處理完善 |
| 託管 | **Cloudflare Pages** | 免費、自動部署、自動 HTTPS、apex + www 支援佳 |
| 表單 | **Web3Forms**（或 Formspree） | 免費、送出即寄 email，無需自建後端 |
| 原始碼 | **GitHub** | 觸發 Cloudflare Pages 自動部署 |

使用者日常只面對 **Sanity 後台** 一個介面；其餘服務由開發者串接，平常無需理會。

切分原則：依「**是否還會變動**」決定進不進後台，而非依年份硬分。

**種貓 Breeding Cat（King / Queen）**

- 毛色花紋
- 血統 / 註冊頭銜（如 TICA、CFA、FIFE）

- 介紹（en / zh-Hans）

**待售幼貓 Kitten（目前批次，即 2026）**
- 名字（en / zh-Hans）
- 照片（一至多張）
- 性別
- 毛色
- 生日
- 狀態（可預約 / 已預訂）
- 介紹（en / zh-Hans）
- （選用）所屬父母 → 關聯到種貓

> 不分語言的欄位（照片、毛色、生日、狀態）只需填一次；文字欄位分 en / zh-Hans 兩格。

### 4.4 年份滾動策略
後台的幼貓只保留「當前還在待售的這一批」。當一批送養完、確定不再變動，由開發者將其「凍結」為與過往一致的靜態歷史頁，後台清空，使用者接著放下一批。→ **後台永遠等於「當前還在賣的貓」**，不會越積越多；歷史頁與當前頁共用同一套樣板，視覺一致。

## 5. 多語系（i18n）

- 語言：英文 `en`（主）、簡體中文 `zh-Hans`。
- 兩種語言各有獨立網址（`/en/...`、`/zh/...`），利於 SEO。
- 右上角語言切換。
- 靜態頁文案：兩種語言皆寫在程式內。
- 後台內容：文字欄位提供 en / zh-Hans 兩格；非語言性欄位只填一次。

## 6. 部署與 DNS

### 日常運作（全自動）
- 開發者改程式 → 推上 GitHub → Cloudflare Pages 自動重建並部署。
- 使用者於 Sanity 改內容 → Sanity webhook 觸發 Cloudflare Pages 部署掛鉤 → 重建 → 數分鐘後上線。

### 表單流程
- 訪客送出表單 → Web3Forms → 寄 email 至設定的貓舍信箱（信箱寫在程式設定檔）。

### DNS（一次性設定，提供逐步教學）
- 網域**繼續註冊在 Wix**，不轉移、不付轉移費。
- 在 Wix 將網域 **Nameserver 改為 Cloudflare**，之後由 Cloudflare 管理 DNS。
- apex（`yourdomain.com`）與 `www` 皆指向 Cloudflare Pages，自動 HTTPS。
- 後備方案：若不改 Nameserver，則於 Wix DNS 面板加 CNAME 指向 Cloudflare Pages（apex 處理較受限，故首選改 Nameserver）。
