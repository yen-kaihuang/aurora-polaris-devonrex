# Shipping Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `/en/shipping` 與 `/zh/shipping` 上線雙語運送資訊頁，呈現 4 種運送方式（大溫哥華、溫哥華島、加拿大國內、國際），視覺風格沿用本站米色卡片設計語言。

**Architecture:** 靜態資訊頁，無互動。新增 `src/pages/[lang]/shipping.astro`（薄殼）與 `src/components/ShippingInfo.astro`（HTML + scoped CSS），i18n 走既有 `src/i18n/ui.ts` 字典，Nav 連結從 `'#'` 改為實際路徑。

**Tech Stack:** Astro 6、TypeScript strict、Vitest

**Spec:** `docs/superpowers/specs/2026-06-20-shipping-design.md`
